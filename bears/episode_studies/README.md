# 《熊出没》四季篇：逐集学习和建模

目标：一集一集研究原作画面，把能确认的建筑、地形、室内、植物、道具和空间关系，逐步复刻到**同一个** Blender 世界（`../blender/`）。
不是一次性堆细节，也不是每集做一张新地图。

## 现实限制（先说清楚）

本环境现在**读不了剧集视频**（2026-10 测试）：

| 入口 | 结果 |
|---|---|
| YouTube 熊出没官方频道（例如 S1E01 `WxGXSaOyP2w`） | 页面能打开，标题能读；播放器返回 `LOGIN_REQUIRED`（“Sign in to confirm you’re not a bot”）。只能拿到封面和 3 张 120×90 自动缩略图 |
| 哔哩哔哩（例如 `BV1dt421K741`） | 接口返回 412（风控拦截） |
| 央视网分集页（例如 `VIDE1417093925245254`） | 页面能打开；视频信息接口返回 404；封面只是央视台标 |

这些都是访问限制，**不绕过**（不用 cookie、不换代理、不用下载工具硬抓）。所以：

- 只有真正看过画面的集，才能标 `VISUALLY_REVIEWED`。缩略图（短边 < 480）、宣传封面、剧情简介都不算。
- 剧情简介只能写进“文字线索”，不能当成画面证据。
- 要推进逐集研究，需要你提供：**本地视频文件**，或**整集的截图**（每个场景多几个角度）。放进来以后用 `../frame_collection/` 的脚本导入，再按下面的流程走。

## 每集的状态

| 状态 | 条件 |
|---|---|
| `NOT_STARTED` | 还没开始 |
| `SOURCES_FOUND` | 找到了视频页面或资料，但还没有能用的画面 |
| `FRAMES_AVAILABLE` | 手里有能用的画面（本地视频或足够清楚的截图） |
| `VISUALLY_REVIEWED` | 逐镜头看过，`episode_report.md` 列出了看过的画面（时间码或文件名） |
| `MODEL_UPDATED` | 根据这一集改了 Blender，`model_changes.md` 写了改了哪些物体 |
| `ACCEPTED` | 做了同机位对照（原作 / 模型 / 差异），不合格的已经改完 |

`tools/check_status.py` 会检查这些条件（例如没有看过的画面却标了 `VISUALLY_REVIEWED` 会报错）。

## 每集的流程

1. **看片和取画面**：记录集数、标题、版本、时长；按镜头变化记下重要场景的时间码；优先保留全景、正面、侧面、俯视和室内画面，同一建筑尽量多角度。不机械地每秒截图。
2. **场景分析**（六类）：A 建筑、B 地形、C 室内、D 自然环境、E 角色和道具（用角色做比例尺）、F 空间关系。镜头切换不等于两个地点相邻。
3. **跨集知识库**：每集一个目录，五个文件（见下）。重复出现的建筑**不重新建模**，而是在 `assets/<资产ID>.md` 里追加证据、修改同一个资产。不同集有冲突时先查是不是季节、版本或透视造成的，保留证据，必要时做不同版本。
4. **改 Blender**：新建筑 → 新资产；旧建筑新角度 → 修几何；新家具 → 放进正确的房间；新道路、地形 → 改路网和地形；季节变化 → `SEASON_*`；只在这一集出现的东西 → `EPISODE_OVERRIDES/EP_<季><集>`（默认隐藏）。
5. **同机位对照**：每集挑 5–10 个最有用的镜头，对齐相机位置、焦距、轮廓、比例、主色、光照方向和物体相对位置。输出“原作 | 模型 | 差异”。修复顺序：整体轮廓 → 主要比例 → 门窗洞口 → 家具布局 → 材质颜色 → 小装饰 → 光照。
6. **本集验收**：看过的画面数量、发现的场景和资产、新增和修改的物体、确认的空间关系、还确认不了的细节、对照图、更新后的 `.blend`、Git 提交。做完才进入下一集；画面不够就记缺口，不虚构成果。

## 目录

| 路径 | 内容 |
|---|---|
| `EPISODE_QUEUE.csv` | 208 集队列（4 部 × 52 集）：状态、看过的画面数、视频来源。集名只填核实过的，其余写“待核实” |
| `ASSETS.csv` | 世界资产数据库：稳定的资产 ID → Blender 根物体 / 集合 → 档案文件 |
| `assets/<资产ID>.md` | 每个重要场景的“原作还原度档案”：跨集证据逐条追加，不另建第二个模型 |
| `<季代码>/E<集>_<集名>/` | 每集五个文件：`episode_report.md`、`scene_inventory.csv`、`spatial_relations.json`、`model_changes.md`、`reference_gaps.md` |
| `templates/` | 新一集的空模板 |
| `tools/init_queue.py` | 生成或补齐队列 |
| `tools/new_episode.py` | 从模板建一集的目录 |
| `tools/check_status.py` | 检查状态是否守规则 |

## Blender 里的图层

- **WORLD_BASE**：现在的地形、森林、木屋、仓库、熊洞、猴洞、松鼠窝、湖等集合，都是跨集共同的场景。
- **SEASON_SPRING / SEASON_SUMMER / SEASON_AUTUMN / SEASON_WINTER**：季节差异。目前只有秋季落叶放在 `SEASON_AUTUMN`；其他季节先空着，等有画面再放。
- **EPISODE_OVERRIDES/EP_<季><集>_<集名>**：单集特有的东西，默认隐藏。用 `../blender/render_episode.py` 临时打开渲染。

## 剧照和版权

剧照、视频帧不进仓库。仓库里只放模型渲染、文字记录和索引。和剧照并排的对照图只发给用户。
