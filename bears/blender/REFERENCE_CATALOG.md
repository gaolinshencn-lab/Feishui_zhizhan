# 参考图逐张核对清单

建模前把参考图按主题分了文件夹，文件名写明主题和视角，例如 `pickup_side_full_scale_vick__S1E1-39.png`。截图只用于本地参考，**不放进仓库**。下面每一行对应一张图。

来源代号：

| 代号 | 来源 |
|---|---|
| S1E1-xx | 第一季第 1 集《新邻居》粉丝维基截图 `ANewNeighborxx` |
| U1–U7 | 用户上传的剧照 |

| 海报 / 立绘 | 四季篇海报、粉丝维基角色立绘 |

使用规则（按用户指令）：

- 以**四季篇**为主要设定：木屋、室内布局、光头强服装都按 U3–U7 和四季篇海报。
- 第一季《新邻居》只参考**不冲突**的内容：森林外观、红棕色粗树干、蓝色皮卡。
- 剧照看不清的地方标为推测，模型上带 `ref_status = inferred`。
